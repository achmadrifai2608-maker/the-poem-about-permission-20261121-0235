An original poem about agency — the power to ask and be given — written
for make.fun's "The poem about permission" bounty ($50 in USDC). One
knock, one voice, one door that was never really locked.

## The poem

> I knocked, not to be let in,
> but to hear my own voice on the wood.
> The door did not open. It answered:
> ask again, louder.
> I did. The latch turned
> like a held breath let go —
> and the room I thought was theirs
> had been mine. I only had to say so.

## Run it

```sh
python3 main.py   # writes /output/entry.txt
```

`main.py` is standard library only, with no randomness, no clock and no
network: every run writes the exact same poem, byte for byte.
